Sử dụng thư viện công cụ

Ở trang web này, bạn có thể tạo hoặc chỉnh sửa các mô hình bằng cách thêm bớt các công cụ, thêm bớt trang, và thay đổi kích thước cửa sổ mô hình. Thiết kế xong, bạn có thể lưu file dưới tên "***-json.js", và có thể tích hợp vào trong các trang web hoặc khóa học phù hợp.

Bạn thêm công cụ vào mô hình bằng cách nhấn vào biểu tượng công cụ trong danh sách ở phía dưới mô hình. Bạn kéo rê thanh cuộn để thấy được nhiều công cụ hơn, hoặc nhấn các nút để xem các tập hợp công cụ khác. Bạn sắp xếp lại hoặc xóa công cụ bằng cách kéo thả danh sách công cụ ở bên trái cửa sổ mô hình.

(Chú ý: nút undo/redo của mô hình sẽ mất tác dụng khi bạn thêm, sắp xếp, hoặc xóa công cụ).

Bạn có thể xóa trang hiện thời bằng cách nhấn nút "Xóa trang", hoặc thêm, nhân đôi trang.

Tải mô hình

Sau khi hoàn thành, bạn lưu mô hình bằng cách chọn Download từ menu (nằm phía dưới trái của cửa sổ mô hình, biểu tượng có 3 gạch ngang).

Để chỉnh sửa một mô hình đã có, bạn chọn Upload từ menu, rồi dẫn đến nơi chứa mô hình.
