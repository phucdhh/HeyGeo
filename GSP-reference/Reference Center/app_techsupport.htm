E-Mail Technical Support

For this field-test edition of new functionality, general Sketchpad technical support is limited. If you have questions on your field-test version of Sketchpad, or to report bugs, please include the full version number of the edition of Sketchpad you’re using. (The full version number — for example, 5.10 (build 3054) — can be located in the program’s About Sketchpad dialog box.)
