New in Release 5.1x (Mac only)

This new Mac version is compatible with MacOS 26 (Tahoe).

You can now "drag merge" independent points to other points or to paths, provided that the object to which the point is being merged is not descended from the point itself. See Tools | Arrow Tools | Drag Merge.

You can redefine a Hide/Show action button to change the specific objects that the button shows or hides. See Menus | Edit Menu | Edit Definition/Redefine.

You can redefine a Presentation action button to change the specific objects that the button presents. See Menus | Edit Menu | Edit Definition/Redefine.

The Translate, Rotate, and Dilate dialog boxes are easier to use.

In the Script View, you can press and hold Next Step(s) to preform multiple steps in a row.

Pinch-zoom Script View's Object List to increase or decrease its text size.

In New Parameter, G rather than A is now the shortcut for "Angle" (think an-GULL), since A generally means "Select All".

You can select multiple pages or tools simultaneously in Document Options, and then drag-rearrange them (in the list of pages and tools), or delete them as a unit.

In the Document Options dialog box, you can use P and T as keyboard shortcuts for PAGES and TOOLS.

When you choose Other Color or use the Text Palette's color picker, the color picker dialog box now recolors the selected objects dynamically while you are trying out different colors.

The Marker tool now produces pressure-sensitive ink, if your hardware supports it.

The JavaSketchpad export option has now been replaced by File | Export as Web Sketch, which creates a fully-functional browser-based version of your sketch suitable for upload to web sites.
